# Portfolio — Paula López Román

Web de portfolio de Paula López Román, diseñadora multidisciplinar.

Sitio estático publicado con GitHub Pages en la ruta `/portfolio`.

- `index.html`: portada.
- `projects/`: índice de proyectos y una carpeta por proyecto.
- `media/`, `audio/`, `fonts/`, `Model/`: imágenes, vídeos, sonidos, fuentes y modelo 3D.

El formulario de «¿Hablamos?» no envía mensajes en GitHub Pages, porque necesita un servidor.
